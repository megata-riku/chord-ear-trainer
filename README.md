# コードの聴き取り単語帳

**コードを聴いて、答える。苦手な響きをくり返す。**

耳コピに向けてコードの響きを覚えるWebアプリです。
単一コードやコード進行を聴いて回答し、間違えた響きを聴き比べられます。
回答履歴から正答確率を予測し、苦手な問題を優先する出題機能も備えています。

## 作ったきっかけ

作曲をしてみたいと思い、好きな曲を耳コピするところから始めようとしました。いざ聴いてみると、どのコードが鳴っているのかまったく分かりませんでした。

英単語を単語帳で覚えるように、コードの響きも、聴いて答える練習をくり返せたらいい。そう考えて、このアプリを作り始めました。回答履歴から苦手なコードやコード進行を見つけ、次の練習に生かす仕組みも加えています。

## まず試す

Node.js 24以降（検証環境：24）。外部npmパッケージのインストール・ビルドは不要です。

ZIPを展開し、`package.json` があるフォルダをVS Codeで開きます。「ターミナル → 新しいターミナル」で、次のコマンドを実行します。

```sh
npm start
```

WindowsのPowerShellで `npm.ps1` の実行が拒否される場合は、`npm.cmd start` を使います。テストは `npm.cmd test`。セキュリティ設定の変更は不要です。終了はターミナルで `Ctrl + C`。

`http://127.0.0.1:8000/` を開き、小さな音量から開始します。最初の音声読み込みには少し時間がかかります。初期状態はステップ練習です。自由練習では調・楽器・回答形式・出題方式を選べます。

ホスト版アプリは現在本人限定です。手元で試す場合は、上記の手順で起動してください。

## 実装した体験

- ピアノ、アコギ、エレキ、合成音3種。12長調・12自然短調、単一コードと2・3コード進行。
- ステップ練習は10問中9問以上で解放。進行4択と順番入力、回答後の比較再生、中断と復習。
- 進行4択はmajor／minor・dimで候補の並びを調整し、候補作成後に正解を等確率で選択。minorとdimの採点は別。
- 自由練習はルール式／モデル式／範囲全体。原則重点5問＋範囲全体5問、履歴がなければ全体10問。
- 全体・同条件の正答率、ロジスティック回帰、決定木、ブースティングを比較。
- 単一コードと順番入力の部分成績、隣接ペア、弱い関連履歴、選択肢に含まれる取り違え相手を予測に利用。
- IndexedDBに回答・練習・モデルを保存。JSONで保存・復元。自動のクラウド同期はありません。

## 設計で重視したこと

1. 出題前に提出された回答だけを特徴量に使い、未来の正誤を混ぜない。
2. 練習回単位の時系列分割で評価。共有設定は学習側の内側検証だけで選択する。
3. 進行4択の誤答から各位置の誤認を推測しない。順番入力の明示的な回答を部分成績に使う。
4. 同一コードは調をまたいで共有し、楽器間はアコギ↔エレキだけ弱く共有。メジャー／マイナーは別の対象として保持する。
5. 少ない履歴で複雑なモデルを強制せず、ルール式への切替理由を保存する。
6. 予測精度と学習効果を分ける。出題後の正答率だけで上達や出題方式の優劣を主張しない。

## 追試と確認

```sh
npm test
npm run demo:data
npm run experiment -- dist/demo-history.json artifacts/demo-report.json synthetic-demo
```

デモ履歴は決定的な人工データ360問です。ブラウザの「履歴を見る→JSONから復元」でも読み込めます。元の回答は上書きされず、別のデモ利用者として追加されます。予測画面でデモ利用者を選びます。**適応出題は現在の利用者の履歴だけを使うため、デモ利用者の取り込みで自分用のモデル式が有効になるわけではありません。**

CLIはブラウザと同じ予測実装を読み込みます。実験JSONには特徴量・正誤・回答IDが含まれるので、個人用の入力は `private-data/`、結果は `artifacts/` などGit管理外へ保存します。`.gitignore` は誤操作を完全に防ぐ仕組みではありません。

## 技術構成・現在地

HTML/CSS/JavaScript、Web Audio、Web Worker、IndexedDB。学習器は小規模で検証しやすいJS実装です。Node.js CLIは同じコードを再利用します。

特徴量設計・時系列評価・比較実験を中心とした作品です。実利用者1人の探索的評価では、同条件の正答率による単純な集計が最良でした。適応出題による学習効果は未検証です。自動再学習・CI/CD・監視基盤は未実装です。

## 開発体制・生成AIの利用

個人制作です。課題設定、機能要件、出題条件や履歴の共有方針の決定、
実際に利用したうえでの改善提案、表示文言の調整を担当しました。
コードの大部分の作成、テストの作成・実行、文書の整備にはChatGPTを利用しています。

音源の出典・ライセンスは [CREDITS](dist/audio/CREDITS.txt) を参照。音源のライセンスをソース全体のライセンスとみなさないでください。個人履歴・音声の外部送信処理は実装していません。サイトへのアクセスや認証などの通信とは別の話です。
